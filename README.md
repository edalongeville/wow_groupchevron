# GroupChevron

A World of Warcraft addon (Interface 16001, WoW: Forever client) that makes the members of your party or raid easy to spot in a crowd. Standalone: no dependency on any other addon, nothing recorded or uploaded.

## Features

A small, separate addon that makes the members of your party or raid easy to spot in a crowd: their nameplate name turns magenta pink (`#FF4FD8`; nothing in the default UI uses it for units) and a discreet fading double down-chevron (two stacked "V", the lower one at 50 %, about 10 × 9 px, in the same colour) sits 2 px above it. **Friends** outside the group (on your character friends list, or a Battle.net friend's character) get their name in blue (`#3FA7FF`, configurable) and the same chevron in that colour (optional); once they join your group they get the member look. **Guildmates** outside the group (and not on your friends list) get their name in green (`#40FF40`, configurable) and the same chevron in that colour (optional). With **compact** on (the default), the other friendly players show **only their name** (the game's colour), plus their health bar while they are hurt, so the friendly nameplates no longer clutter the screen; targeting one of them shows their full plate. With **class colour** on (off by default), those other friendly players' names are drawn in their class colour, as in Blizzard's default UI. Friendly players outside the group (friends, guildmates and class-coloured ones included) show their **level** after their name on name-only (compact) plates, e.g. `Garzak (19)` (`showlevel`, default on); wherever their health bar is shown (full plates, your target, a hurt compact plate), Blizzard's level beside the bar replaces it. Everyone else's plate (enemies, NPCs, the target) is left as the game draws it.

- **Install:** copy the `GroupChevron` folder into `World of Warcraft/<flavor>/Interface/AddOns/` (e.g. `_classic_era_`). Its settings live in `WTF/` (`GroupChevronDB`) and survive removal.
- **Needs the friendly player nameplates** (`V` / `Shift+V`); at login it says so once in chat when they are off.
- **`/gchev`**: prints the state (on/off, colour, which name field was found, plates marked, compact on/off and plates in compact mode). `/gchev on` / `off` (off restores the names' colour at once), `/gchev color #RRGGBB` (invalid input is refused and changes nothing), `/gchev chevsize <1-5>` (chevron size factor; the only factor that goes up to 5) and `/gchev textsize <1-3>` (name text size factor), both for group members only, `/gchev barsize <1-3>` and `/gchev buffsize <1-3>` (group members' health bar and buffs: `SetScale` on `UnitFrame.HealthBarsContainer` (else `.healthBar`) and `UnitFrame.AurasFrame`, times the scale Blizzard had set, given back when the plate leaves member mode; since 0.6.1 the bar also widens: Blizzard stretches `HealthBarsContainer` between the top corners of `CastBarsContainer`, and nameplate regions cannot be measured (`GetPoint`/`GetWidth` fail with "Can't measure restricted regions"), so it is laid out again from Blizzard's own layout values (`NamePlateSetupOptions.castBarToHealthBarSpacing` and `insetWidth`, `NamePlateDriverFrame:GetNamePlateWidth`) with offsets from `Core.BarOffsets`, about its centre, bottom unchanged, and laid out back the same way at size 1 (any of those missing: height only, one chat notice); a bar at size 1 is never re-anchored; `buffsize` above 1 also lifts a member's name, and so the chevron, by half of what a buff icon gains (`Core.BuffLift`, from `NamePlateConstants.AURA_ITEM_HEIGHT` and the aura frame's `auraItemScale`), since Blizzard centres the buffs on the left of the bar), `/gchev othersize <1-3>` and `/gchev otherbarsize <1-3>` (name text and health bar size of friendly players outside the group: the name-only plates of compact mode and, since 0.17.1, the full plates of friends, guildmates and class-coloured players when compact is off; since 0.17.2 every friendly non-member's full plate, your target included, compact on or off; buffs stay hidden on compact plates), default `1`, decimals allowed (`1.25`); a value that is not a number or outside 1–3 (`chevsize`: 1–5) is refused with a message and changes nothing (no clamping); without a value they print the current one; `textsize` scales the addon's own name frame (see Full name below), never Blizzard's font; `/gchev friendcolor #RRGGBB` (friends' colour, default `#3FA7FF`; without a value it prints the current one), `/gchev friendchevron on` / `off` (the chevron above friends, default on) and `/gchev bnetfriends on` / `off` (count Battle.net friends, default on), refused and changing nothing on invalid input, printing the current value without one; `/gchev guildcolor #RRGGBB` (guildmates' colour, default `#40FF40`) and `/gchev guildchevron on` / `off` (default on), same validation; `/gchev level on` / `off` (the level after friendly players' and guildmates' names, default on; same validation); `/gchev compact on` / `off` (name-only plates for friendly non-members, default on; anything else is refused and changes nothing; without a value it prints the current one; off restores every plate at once, so does `/gchev off`); `/gchev classcolor on` / `off` (also `classcolour`; other friendly players' names in their class colour, default off; same validation, without a value it prints the current one; `/gchev` prints it with the number of plates coloured); `/gchev reset` (default member colour only), `/gchev options` (opens the settings page, see below; a message, never an error, when the client has no Settings canvas API or refuses it, e.g. in combat), `/gchev names` (changes nothing, needs no target: lists every visible plate whose Blizzard name is not visible (alpha below 1, or hidden) and not covered by the addon's own name, with its unit, alpha, shown state and whether the addon still remembers fading it, then the driver hook call counts and the failed name restores), `/gchev debug` (on the current target's plate: the name field found, whether the target counts as a group member, whether it counts as a friend and which source answered (character list, Battle.net, none, no readable GUID, API missing; `/gchev` prints the same for the current target), whether it counts as a guildmate and which API answered, Blizzard's name alpha and shown state on that plate, whether the addon's name covers it, the faded names still pending, whether the nameplate driver hooks are installed and how often they ran, and the number of failed name restores, its class token and class colour (`unknown` / `none` when they cannot be read), the `classcolor` setting and the colour its name gets (member, friend, guild, class or Blizzard's), its mode, and the parts compact mode hides there, or would hide since the target itself is always shown in full, each with its name (frame name, else its field on `UnitFrame` or the name's ancestors) and object type: this is how to check which parts exist on the Forever client). Changes apply at once to the visible plates and are saved in `GroupChevronDB` (`enabled`, `color` = `{ r, g, b }` in 0..1, `chevsize` = 1..5, `textsize`, `barsize`, `buffsize`, `othersize`, `otherbarsize` = 1..3, `compact` = boolean, invalid = on; `friendcolor` = `{ r, g, b }`, invalid = `#3FA7FF`; `friendchevron`, `bnetfriends` = boolean, invalid = on; `guildcolor` = `{ r, g, b }`, invalid = `#40FF40`; `guildchevron` = boolean, invalid = on; `classcolor` = boolean, invalid = off; `showlevel` = boolean, invalid = on).
- **Settings page (Options → AddOns → GroupChevron):** every setting above as plain widgets on our own canvas, in groups under Enabled: **Group members** (name colour, chevron size, text size, health bar size, buffs size, name height), **Friendlies** (friendly players outside the group: compact plates, class colour, Show level, text size, health bar size, name height), **Friends** (name colour swatch, Show chevron, Include Battle.net friends) and **Guildmates** (name colour swatch, Show chevron), registered with `Settings.RegisterCanvasLayoutCategory` / `Settings.RegisterAddOnCategory` only when those exist (otherwise skipped silently; the slash commands keep working): Enabled and Compact plates checkboxes, a name-colour swatch (`ColorPickerFrame:SetupColorPickerAndShow`: applied live, Cancel restores the previous colour, no opacity), size sliders (chevron size 1–5, the rest 1–3, step 0.05, applied on release) and **Reset to defaults** (all settings: `#FF4FD8`, friends `#3FA7FF` with chevron and Battle.net friends on, guildmates `#40FF40` with chevron on, class colour off, level on, every size 1, enabled, compact on; `/gchev reset` still resets the member colour only). The panel and the slash commands call the same setters (`SetEnabled`, `SetCompact`, `SetColor`, `SetFriendColor`, `SetGuildColor`, `SetFlag`, `SetFactor`, `ResetAll`), which validate through `Core`, save, and refresh the plates at once; the panel reads `GroupChevronDB` each time it is shown. Needs an in-game check (the stub-based specs cannot cover the real widgets).

Implementation notes (modes, relations, fonts, sizes, localisation, how plates are handled) are in [docs/TECHNICAL.md](docs/TECHNICAL.md).

## Layout

| Path | Content |
|---|---|
| `GroupChevron/` | the addon: `Core.lua` (pure, unit-tested logic), `GroupChevron.lua` (WoW glue), `.toc`, `chevron.tga`, `icon.tga` |
| `assets/` | CurseForge project icon (`curseforge-icon.png`, 400×400) |
| `docs/` | implementation notes |
| `spec/` | [busted](https://lunarmodules.github.io/busted/) tests (`Core.lua` and a smoke test of the glue against a stubbed WoW API) |
| `tools/` | generators for `chevron.tga` and `icon.tga` (Python 3, no dependencies) |
| `.luacheckrc` | luacheck configuration (Lua 5.1, WoW globals) |

## Development

Lua 5.1, as in the WoW client. Keep logic that does not need the WoW API in `Core.lua`, with tests in `spec/`.

```bash
luacheck . && busted --lua=lua5.1 spec
```

Regenerate the textures from the repository root:

```bash
python3 tools/chevron_tga.py GroupChevron/chevron.tga
python3 tools/groupchevron_icon_tga.py GroupChevron/icon.tga
python3 tools/curseforge_icon_png.py assets/curseforge-icon.png
```

Bump `## Version` in `GroupChevron/GroupChevron.toc` with every change to the addon (patch for fixes, minor for features).
